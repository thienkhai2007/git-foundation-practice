## 2. Nhật ký quá trình học tập và thực hành Git

### Giai đoạn 1: Học tập nền tảng Git/GitHub

Hoàn thành các mô-đun GitHub Foundations trên Microsoft Learn. Trong quá trình học, em đã tìm hiểu và nắm được các kiến thức cơ bản về:

* Repository và Version Control
* Commit và lịch sử thay đổi
* Branch và GitHub Flow
* Pull Request và Code Review
* GitHub Issues và Project Management
* Bảo mật Repository và thực hành làm việc nhóm

### Giai đoạn 2: Xây dựng Repository thực hành

Em đã tạo một GitHub Repository cá nhân để thực hành các thao tác Git cơ bản và nâng cao:

* Tạo repository và kết nối local với GitHub
* Thực hiện nhiều commit có ý nghĩa
* Tạo và quản lý các branch riêng biệt
* Đồng bộ dữ liệu giữa local và remote repository
* Thực hành GitHub Flow thông qua Pull Request

### Giai đoạn 3: Thực hành quản lý thay đổi và xử lý lỗi

Để mô phỏng các tình huống thực tế khi phát triển phần mềm, em đã:

* Tạo nhiều branch phục vụ phát triển tính năng
* Tạo và merge Pull Request
* Thực hành tạo xung đột (Merge Conflict) và xử lý thủ công
* Thực hiện rollback/revert khi phát sinh thay đổi không mong muốn
* Kiểm tra lịch sử commit và khả năng khôi phục phiên bản ổn định

## 3. Danh sách lệnh Git đã sử dụng

Trong quá trình thực hành, em đã sử dụng các lệnh Git sau:

* git clone <repository_url>
* git status
* git add .
* git commit -m "message"
* git push origin <branch_name>
* git pull origin <branch_name>
* git branch
* git checkout <branch_name>
* git checkout -b <branch_name>
* git merge <branch_name>
* git revert <commit_id>
* git log --oneline
* git reset --hard origin/main

## 4. Kết quả thực hành

### Commit

* Hoàn thành tối thiểu 10 commit có ý nghĩa.
* Các commit được đặt tên rõ ràng và phản ánh đúng nội dung thay đổi.

### Branch

Đã tạo và sử dụng các branch:

* main
* feature-1
* feature-2
* feature-conflict

### Pull Request

Đã tạo tối thiểu 02 Pull Request để thực hiện quy trình review và merge code.

### Conflict

Đã thực hành tạo Merge Conflict bằng cách chỉnh sửa cùng một nội dung trên hai branch khác nhau và tiến hành xử lý xung đột thành công.

### Rollback/Revert

Đã thực hiện git revert để hoàn tác một commit lỗi và khôi phục trạng thái ổn định của dự án mà vẫn giữ nguyên lịch sử thay đổi.
